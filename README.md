## Installation Guide

Follow these steps to install the extension manually in Google Chrome using Developer Mode.

### Step 1: Download & Extract
1. **Download** the latest release `.zip` file from [Releases Link Here](#).
2. Locate the downloaded file on your computer and **Extract/Unzip** it. 
   > **Note:** Keep the extracted folder in a permanent directory (e.g., `Documents` or a dedicated `Extensions` folder). If you delete or move this folder later, the extension will stop working.

### Step 2: Enable Developer Mode in Chrome
1. Open Google Chrome and navigate to `chrome://extensions/` *(or go to **Menu** > **Extensions** > **Manage Extensions**)*.
2. Toggle on **Developer Mode** in the top-right corner.

### Step 3: Load the Extension
1. Click the **Load unpacked** button in the top-left corner.
2. Select the **extracted folder** from Step 1 (the folder containing `manifest.json`).
3. The extension is now installed! Pin it to your toolbar for easy access.
